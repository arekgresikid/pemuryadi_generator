# Panduan Menulis Artikel

Selamat datang di platform penulisan blog Digen.id!

Karena sistem ini menggunakan format **Markdown** murni (bukan seperti Microsoft Word), Anda perlu mengetikkan beberapa simbol khusus untuk mengatur format tulisan agar rapi. Jangan khawatir, caranya sangat mudah dan cepat dipelajari!

## Kode Format Penulisan (Sintaks Markdown)

Berikut adalah panduan lengkap cara menulisnya:

### 1. Membuat Judul
Sistem akan otomatis menjadikan baris pertama berawalan `#` sebagai Judul Artikel. Untuk membuat sub-judul di dalam artikel, gunakan `#` lebih dari satu.

```text
# Ini adalah Judul Utama Artikel (Cukup di awal tulisan)

## Ini adalah Sub-Judul (Bagian dari artikel)
### Ini Sub-Judul yang lebih kecil lagi
```

### 2. Menebalkan dan Memiringkan Teks
Apit kata atau kalimat Anda dengan tanda bintang (`*`):

```text
Gunakan dua bintang untuk membuat teks **Tebal**.
Gunakan satu bintang untuk membuat teks *Miring*.
```

### 3. Membuat Daftar (Poin-poin)
Gunakan tanda strip (`-`) untuk poin biasa, atau angka untuk nomor urut. Beri spasi setelah simbol tersebut:

```text
- Poin pertama
- Poin kedua
- Poin ketiga

1. Langkah pertama
2. Langkah kedua
```

### 4. Memasukkan Link (Tautan)
Gunakan kurung siku `[]` untuk teks yang bisa diklik, langsung diikuti dengan kurung biasa `()` berisi alamat web/URL:

```text
Silakan baca panduan resminya di [Kemdikbud](https://kemdikbud.go.id).
```

### 5. Memasukkan Gambar
Caranya persis sama seperti memasukkan *link*, tapi tambahkan tanda seru `!` di paling depannya:

```text
![Deskripsi Gambar](https://alamat-website-gambar.com/foto-kegiatan.jpg)
```

---

**Catatan Penting Setelah Menulis:**
Artikel yang baru saja Anda simpan tidak akan langsung tayang ke publik. Artikel tersebut akan berstatus **Pending**. Anda atau admin lain harus membuka menu **Administrasi** di web ini, lalu menyetujuinya (*Approve*) agar dapat dibaca oleh umum. Selamat menulis!
