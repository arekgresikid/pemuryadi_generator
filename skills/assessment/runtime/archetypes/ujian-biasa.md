# Archetype: Ujian Biasa (Formatif, STS, SAS, Ujian Sekolah)

- **Kebijakan Stimulus**: Hybrid proporsional (~65–75% soal mandiri `STANDALONE` / `EMBEDDED_CONTEXT` tanpa wacana panjang; maksimal 2–3 wacana bersama di `stimulusList` untuk soal kontekstual/HOTS).
- **Distribusi Kognitif**: Proporsional sesuai pilihan guru (L1 Pemahaman, L2 Aplikasi, L3 Penalaran HOTS).
- **Bentuk Soal**: Pilihan Ganda, Pilihan Ganda Kompleks, Benar/Salah, Menjodohkan, Isian Singkat, Uraian.
