# Archetype: Olimpiade Sains (OSN / IMO / IPhO / IChO / IBO)

- **Karakteristik**: Penalaran multi-langkah (*multi-step deductive reasoning*), analisis kasus batas (*corner cases*), pemodelan matematis/ilmiah, dan pembuktian.
- **Pembahasan**: Wajib memuat langkah penyelesaian formal yang sah, asumsi eksplisit, dan verifikasi hasil.
